# Multi-Step Form with Progress Indicator

A multi-step registration form built for my internship task. Users fill in their details one step at a time, with a progress bar, validation, and a final summary before submitting.

Live demo: https://hinaayoub717.github.io/multi-step-form/

## Features
- Four steps: Personal, Contact, Account and Review
- Progress bar and step circles that update as you move
- Validation of required fields before moving to the next step
- Final summary screen with an edit button for each field
- Slide animations between steps
- Autosave in localStorage, so progress is kept after a page refresh (passwords are never saved)

## Built with
HTML, CSS and JavaScript

## What I learned
- JavaScript form validation
- CSS animations for step transitions
- Next and Previous button functionality
- Saving and restoring data with localStorage

## How to run
Open `index.html` in your browser.
